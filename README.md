# 목회 플러그인 제작소

사역 분야와 작업 유형을 선택하고 구상을 입력하여 ChatGPT에 전달할 플러그인 제작 요청문을 만듭니다.

웹사이트: https://leewha1207-cpu.github.io/ministry-plugin-studio/

이 저장소는 공개 웹사이트 파일만 포함합니다. 개인 플러그인과 참조 자료는 포함하지 않습니다.

## 배포
GitHub Pages에서 main 브랜치의 루트 폴더를 배포합니다. 빌드나 API 키가 필요하지 않습니다.

## 사용
설계안 만들기 → 제작 요청문 전체 복사 → ChatGPT에서 제작 진행. 실제 등록에는 지원 도구와 계정 권한이 필요합니다.
