    01 / 사이트에서 설계

    구상을 담고 요청문 복사

    사역 분야와 작업을 고르고 구상을 입력하세요. ‘설계안 만들기’를 누르면 설계안과 제작 절차가 담긴 요청문이 나옵니다. 내용을 확인한 뒤 전체를 복사하세요.

    02 / ChatGPT에서 제작

    붙여 넣고 단계대로 진행

    ChatGPT에서 Plugin Creator를 사용할 수 있다면 선택한 뒤 요청문을 붙여 넣으세요. 설계 검토, 필요한 질문, 파일 제작, 테스트를 이어가도록 요청합니다. 도구가 없는 환경에서는 파일 내용과 다음 절차를 안내받습니다.

    03 / 등록과 사용 확인

    등록 상태와 결과 점검

    등록은 제작 도구와 계정 권한이 있는 환경에서 진행합니다. 복사만으로 자동 설치되는 것은 아닙니다. 실제 등록 여부와 호출 방법을 확인하고, 예시 요청으로 완성된 플러그인을 테스트하세요.

    이 사이트는 제작 요청문을 준비합니다. ChatGPT에서의 응답과 실제 등록 가능 여부는 사용하는 도구 및 계정에 따라 달라집니다.
